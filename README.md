# App Privacy Policies

Public privacy policy pages for apps published to the Google Play Store, served via
[GitHub Pages](https://pages.github.com/).

Live site: `https://<your-github-username>.github.io/app-privacy-policies/`

## Adding a new app

1. Create a new folder named after the app, e.g. `my-new-app/`.
2. Add a `privacy.md` file inside it with the policy content (front matter `title:` + markdown body).
3. Add a link to it from `index.md`.
4. Commit and push — GitHub Pages rebuilds automatically.
